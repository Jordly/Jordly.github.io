# 2026-08-11 工作日志

## Bug 修复：系统数据管理 - 展开/折叠全部按钮失效

**根因**：`modules/systemData.js` 第 488-489 行的两个按钮 onclick 只设 `window._sdAllExpanded` 后调 `renderModule('systemData')`，但**没清 `_moduleCache['systemData']`**。

`renderModule()` 内部第 2915 行检查 `cached.version === _dataVersion` → 命中缓存 → 直接返回上次存的 HTML → 看起来无反应。

**修复**：onclick 加 `_moduleCache['systemData']=null`，与模块内其他函数（catalogSearchSystemData、searchSystemData、goSystemDataDetail 等）保持一致。

## 经验教训（待写入 MEMORY.md）

**新铁律**：所有修改 UI 全局状态的按钮/操作（折叠/展开/排序/视图切换/等），onclick 必须包含 `_moduleCache[当前模块]=null`，否则 renderModule 会复用缓存 HTML 导致"无反应"假象。

涉及过的同类 bug：
- 2026-08-10: 绩效看板 Tab 切换（performance.js）
- 2026-08-10: 高级筛选点击确定后顶部标签不刷新（app.js applyFbMulti/clearFbMulti）
- 2026-08-10: 权限管理勾选无反应（app.js togglePermAction/togglePermScope）
- 2026-08-11: 系统数据管理展开/折叠全部（systemData.js）

**通用排查模式**：用户报"按钮无反应"或"改了没刷新" → 先 grep 该 onclick 是否有 `_moduleCache[X]=null`，没有就是它。
