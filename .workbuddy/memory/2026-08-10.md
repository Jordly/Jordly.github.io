# 2026-08-10 工作日志

## 筛选栏修复（5个Bug一口气修复）

### 1. 高级筛选顶部标签不刷新
- **根因**: `applyFbMulti`/`clearFbMulti` 改了 filterState 但漏了 `_moduleCache[currentModule]=null`
- **现象**: 第二行选品类/品牌后点确定，顶部 tags-row 不出现，需再点第一行才出现
- **修复**: 两个函数加缓存清理 + sessionStorage 持久化

### 2. PM/Director trigger 重复箭头
- **根因**: pmLabel 默认 "项目PM ▼" 嵌了 ▼ unicode，外层又包了 svg 箭头 → 两个箭头
- **修复**: 删掉默认 label 里的 ▼ 字符

### 3. PM/Director 改为多选（用户诉求：想连续选多个PM/总监）
- 改 filterState.pm/director 从 `'all'` → `[]`
- Panel 加全选/清空/确定按钮
- onFbOptionClick / renderFbOptions isMulti 判定扩展到 pm/director
- getFilteredProjects 改用 .includes() 过滤
- 兼容旧 sessionStorage 的 `'all'` 字符串值

### 4. 项目全景弹窗头部 meta 区对齐
- **根因**: .project-detail-meta 默认 flex stretch，badge(padding 2px) vs wp-tag(padding 1px) 高度差
- **修复**: CSS 加 `align-items: center` + `flex-wrap: wrap`

### 5. 绩效看板 Tab 切换失效
- **根因**: 点"薪资测算"/"基础配置"设了 window._perfTab 但没清 `_moduleCache['performance']` → 缓存命中旧 HTML
- **修复**: 每个 Tab 的 onclick 加 `_moduleCache['performance']=null`
